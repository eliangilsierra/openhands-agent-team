# Documentation

The documentation of this project follows [Diátaxis](https://diataxis.fr/): each page answers one kind
of need. The Technical Writer agent keeps it current after each feature; agents and humans change it only
through `docs/` Pull Requests.

| Section | Use it to | Contents |
| --- | --- | --- |
| [Tutorials](tutorials/README.md) | Learn by doing, from zero to a working result | Getting started |
| [How-to guides](how-to/README.md) | Solve one concrete task | Configure, deploy, operate, troubleshoot |
| [Reference](reference/README.md) | Look up exact facts | API, configuration, commands, data model |
| [Explanation](explanation/README.md) | Understand why | Concepts, design rationale, trade-offs |
| [Architecture](architecture/README.md) | See how the system is built | arc42 overview, C4 diagrams, per-feature designs |
| [Decisions](decisions/README.md) | See what was decided and why | Architecture Decision Records |
| [UX design](design/README.md) | See how the interface should behave | UX specifications per feature |
| [Research](research/README.md) | See the evidence behind decisions | Research reports |
