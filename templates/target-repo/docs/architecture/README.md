## Per-feature architecture documents

Architecture documents of this project, one per feature or component that needed a design. The
Architect agent writes them with the team template (`templates/architecture.md` in the team
repository) on a `docs/<issue-number>-<short-description>` branch; a human merges them into
`develop`.
